Acessos do painel MC

  pular UsuárioTelefoneExpiraFaltamStatusNota

Digite o telefone na caixinha e toque salvar para cadastrar ou corrigir — a máscara já coloca (DDD) nnnnn-nnnn e o 55 do Brasil entra sozinho. Funciona também nos parados. Mesclar marca os usuários: o primeiro empresta o telefone para o segundo e nada é apagado. O botão recuperar manda o PIX pelo WhatsApp para o telefone guardado na linha. Não recuperados abre a coluna pular: marque só quem não deve receber, em qualquer página, e o envio vai para todos os vencidos do painel — inclusive das páginas que não estão na tela.

O que sai quando você clica em “recuperar”

O botão fica na aba Acessos, nas linhas vencidas. Tudo aqui vale para todo clique, sem precisar mexer em mais nada.

Usar no código

        
Toda ação do painel está atrás do login, então o navegador nunca vê
          chave nenhuma. Lá na função:

        
import { encurtar } from "./encurtador.ts";
await encurtar("https://...", "pix", "renovacao");
// { ok: true, curto: "https://.../pix", alvo: "https://...", visita: false }

        
Se o encurtador estiver fora, volta ok=false e nada quebra:
          quem chama usa o endereço comprido.
